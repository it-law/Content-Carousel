
# Content-Carousel

Content-Carousel — это небольшой **AI‑сервис** для генерации и упаковки экспертного контента в формат «карусели»: посты, структуры слайдов, тезисы для презентаций и сторис.

## Возможности

- Генерация контент‑каруселей по заданной теме через простую форму (тема, аудитория, цель).
- Настройка параметров карусели: количество слайдов, тон и стиль текста, уровень формальности. 
- Автоматическое разбиение материала на слайды с заголовками и объяснениями для каждого шага.
- Копирование готового текста карусели одним кликом для верстки в Telegram, соцсетях или презентациях.
